Synthetic text placards for CameraChannel OCR smoke. Manifest lists expected
sign text, ROI, and bearing/range. PNGs are generated by
`parcel_robot.storefront.placards` (stdlib zlib) on first load.

Packaged copy: `src/parcel_robot/runtime_assets/fixtures/storefronts/`.

**Does not prove** wild storefront precision — see HR-4 / `P3_OCR_STATUS.md`.
