# Physics Glossary for Robot Builders

| Term | Practical meaning for Parcel |
| --- | --- |
| **Acceleration** | Rate of change of velocity. Includes changing direction even when speed is constant. |
| **Accuracy** | Closeness to the true value; different from repeatability or precision. |
| **Aliasing** | A high-frequency physical signal appearing as a false lower-frequency signal after inadequate sampling. |
| **Angular momentum** | Rotational counterpart of linear momentum; depends on angular velocity and mass distribution. |
| **Back EMF** | Voltage generated by a spinning motor that opposes the applied voltage and grows with speed. |
| **Bandwidth** | Frequency range over which a sensor, controller, or physical system responds usefully. |
| **Bias** | Persistent measurement offset, such as a gyro reporting nonzero rate while still. |
| **Capture point** | In a simplified inverted-pendulum model, the support location needed to bring current center-of-mass motion to rest without another step. It is not a general fall detector. |
| **Center of mass (CoM)** | Weighted average location of a body's mass; payload position can move it. |
| **Closed loop** | A controller measures the result and corrects future output. Sport's balance loop is closed loop. |
| **Compliance** | Ability to deform under force. Compliance can absorb impacts but reduce positioning stiffness. |
| **Contact force** | Force exchanged where the feet, body, or payload touch another object. |
| **Coordinate frame** | Origin and axes that give a vector or pose physical meaning. |
| **Damping** | A process that dissipates oscillation energy, often approximately proportional to velocity. |
| **Degree of freedom (DoF)** | Independent coordinate required to describe a configuration. Go2 has three actuated joints per leg. |
| **Derivative** | Instantaneous rate of change; velocity is the time derivative of position. |
| **Dimensional analysis** | Checking an equation using base units before trusting its number. |
| **Displacement** | Vector from start to finish, unlike total path distance. |
| **Drag** | Fluid force opposing relative motion, commonly growing roughly with speed squared. |
| **Duty factor** | Fraction of one gait cycle that a particular foot spends in stance. |
| **Dynamic stability** | Remaining recoverable while moving; not captured by a stationary support-polygon test alone. |
| **Efficiency** | Useful output energy or power divided by input; always at most one for a passive conversion. |
| **Energy** | Capacity to do work; conserved in an isolated system even though useful mechanical energy becomes heat. |
| **Estimate** | Best computed belief about a physical quantity from incomplete, noisy measurements. |
| **Fatigue** | Damage accumulation under repeated loading, even below a one-time failure load. |
| **Force** | Interaction that changes momentum; measured in newtons. |
| **Free-body diagram** | Sketch of one isolated body and every external force acting on it. |
| **Frequency** | Cycles or updates per second, measured in hertz. |
| **Friction** | Tangential contact force that resists relative motion; static friction is a bounded response, not always `mu N`. |
| **Gait** | Repeating schedule of stance and swing contacts used to move and support a legged body. Unitree Sport owns this schedule in Parcel's current hardware path. |
| **Impulse** | Force accumulated over time, equal to change in momentum. |
| **Inertia** | Resistance to acceleration. Mass is linear inertia; moment of inertia is rotational. |
| **Integral** | Accumulation over an interval; displacement is the integral of velocity. |
| **Inverse kinematics (IK)** | Computing joint configurations that place a link or foot at a desired pose; solutions may be multiple, absent, or unsafe. |
| **Jacobian** | Configuration-dependent local map from joint rates to task-space velocity; its transpose maps a consistently defined task-space force to generalized joint torque. |
| **Jerk** | Rate of change of acceleration; high jerk feels abrupt and excites flexible structures. |
| **Kinematics** | Geometry of motion without asking which forces caused it. |
| **Kinetic energy** | Energy of motion, proportional to mass and speed squared. |
| **Latency** | Delay between physical event, observation, decision, command, and effect. |
| **Load path** | Route through which force travels from point of application into supports. |
| **Mass** | Measure of inertia in kilograms; not the same as weight. |
| **Momentum** | Mass times velocity; stopping requires an impulse. |
| **Normal force** | Contact force perpendicular to a surface; it is not automatically equal to weight. |
| **Open loop** | Command issued without measuring and correcting its physical result. |
| **Oscillation** | Repeated variation around equilibrium due to energy exchange and restoring forces. |
| **Pose** | Position plus orientation relative to a named frame. |
| **Power** | Rate of energy transfer; measured in watts. |
| **Precision** | Repeatability or resolution of measurements; a precise sensor may still be biased. |
| **Pressure** | Normal force per area. |
| **Resonance** | Large response when excitation aligns with a lightly damped natural mode. |
| **Rigid body** | Approximation that distances within an object remain fixed; real bodies always deform somewhat. |
| **Sampling rate** | Number of discrete measurements per second. |
| **Shear** | Force or stress parallel to a surface. |
| **Singularity** | Configuration where a kinematic Jacobian loses rank, so some local motion directions are unavailable and inverse mappings become ill-conditioned. |
| **Slip** | Relative motion at a contact that was assumed stationary. |
| **Specific force** | Non-gravitational acceleration measured by an accelerometer; a resting accelerometer reads support against gravity. |
| **Sport controller** | Unitree's onboard high-level locomotion controller. Parcel requests bounded body velocity; Sport owns fast gait, balance, foot placement, and actuator execution. |
| **Stance** | Portion of a gait cycle during which a foot supports or interacts with the ground. |
| **Stiffness** | Force needed per unit deformation; inverse of compliance in a simple linear model. |
| **Strain** | Relative deformation, such as change in length divided by original length. |
| **Stress** | Internal force per area within a material. |
| **Support region** | Ground region spanned by active contacts for a static stability approximation. |
| **Swing** | Portion of a gait cycle during which a foot is repositioned and does not provide ordinary stance support. |
| **Time constant** | Characteristic time for a first-order system to make about 63% of a step response. |
| **Torque** | Turning effect of a force about a point or axis; measured in newton metres. |
| **Trajectory** | Time-indexed path containing expected position, velocity, and sometimes acceleration. |
| **Twist** | Linear and angular velocity of a rigid body, expressed in a named frame. Parcel's application boundary uses the planar subset `(vx, vy, vyaw)`. |
| **Uncertainty** | Quantified lack of knowledge; not merely “noise” and never a reason to omit units. |
| **Vector** | Quantity with magnitude, direction, and frame, such as velocity or force. |
| **Velocity** | Rate of change of position, including direction. Speed is only its magnitude. |
| **Voltage** | Electrical potential energy per unit charge. |
| **Work** | Energy transferred by force through displacement. |
| **Yaw** | Rotation about the local vertical axis in the common planar robot convention. |
| **Zero-moment point (ZMP)** | Under restrictive contact assumptions, a support-plane point where the modeled net ground-reaction wrench has no moment about axes tangent to that plane. |

For symbols and units, use the [formula sheet](FORMULA_SHEET.md). For their placement in the stack, use the [robotics glossary](../robotics-60-days/GLOSSARY.md).
