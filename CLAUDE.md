# Parcel — working notes for agents

- **Orient from the index, not the tree.** `CODEBASE_INDEX.md` maps every tracked module, test group, card folder, and the marked regions inside shared product files. Read it selectively: `grep -n '^## \|^### ' CODEBASE_INDEX.md` for the table of contents, then `sed -n 'A,Bp'` for one section. Regenerate after commits that add/move files: `.parcel/bin/python tools/codebase_index.py` (`--check` says if stale).
- **Environment.** Python lives in `.parcel/` (`.parcel/bin/python`, `.parcel/bin/ruff`); system python cannot import the project. Gate: `.parcel/bin/python scripts/ci_gate.py --tier commit` with `TMPDIR` unset (a long TMPDIR breaks the unix-socket tests). The ruff ratchet is a fingerprint baseline (`scripts/ci_ruff_baseline.json`) — add none.
- **Never `pytest -n auto` on this host** (192 cores → 192 workers; four sessions died of kernel OOM on 2026-08-22/23). Run every pytest and every gate through `~/.cache/parcel-guard/pytest_guard.sh --label <who> .parcel/bin/python -m pytest …` (caps at 8 workers, 40 GB cgroup, one suite at a time); `ci_gate.py` honours `PARCEL_XDIST_WORKERS` and never defaults to `auto`. Executors never run `ci_gate.py --tier`; the integrator runs it once at close.
- **Sprint record.** `scrum/<date>/TASK_BOARD.md` carries the standing rules for that wave; each card is `scrum/<date>/task_N/README.md`, its executor report `*_STATUS.md`, the verifier's record `AUDIT_*.md`. Several agent sessions share this one working tree: edit only your card's OWNS, by marked region in shared files, and treat git as read-only unless you are the designated verifier.
- **Owner facts that are easy to get wrong.** No robot hardware is on hand (only the reSpeaker XVF3800 mic array); the owner's memory store `parcel_memory.sqlite3` is never opened read-write by tests; the owner's live stack on `:8765` / `/tmp/parcel_sim.sock` is never killed.
